# Proyecto 2 — Entrega única: Club Deportivo Séneca

Evolución del Proyecto 1 (DPOO, grupo G03). Parte del código de `Proyecto 1/Entrega 2/` y le agrega los torneos internos, las pruebas con JUnit y una consola por cada tipo de usuario.

## Contenido

| Carpeta | Qué tiene |
|---|---|
| `ClubDeportivoseneca/` | Proyecto Eclipse (Java 21). |
| `ClubDeportivoseneca/src/` | Código fuente, organizado en paquetes por área. |
| `ClubDeportivoseneca/datos/` | Datos persistentes en archivos de texto. La aplicación los carga al iniciar y los guarda al terminar. |
| `ClubDeportivoseneca/diagramas/` | Diagramas de clases: fuente PlantUML (`.puml`) e imagen (`.png`). |

## Cómo ejecutar

> Pendiente: se completa cuando estén las tres consolas y las pruebas JUnit.

El directorio de trabajo tiene que ser `ClubDeportivoseneca/`, porque la aplicación busca la carpeta `datos/` ahí.
